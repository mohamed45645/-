# Khadma Hub - React Version

تم تحويل منصة Khadma Hub إلى تطبيق React.

## البدء

### المتطلبات
- Node.js و npm مثبتة على جهازك

### التثبيت

1. قم بتثبيت المكتبات المطلوبة:
```bash
npm install
```

2. قم بتشغيل التطبيق:
```bash
npm start
```

سيتم فتح التطبيق تلقائيًا في `http://localhost:3000`

## البناء للإنتاج

```bash
npm build
```
